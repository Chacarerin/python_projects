¡Bienvenido/a a mi colección de utilidades y aplicaciones desarrolladas en Python! Este repositorio agrupa múltiples herramientas prácticas creadas para automatizar tareas, generar documentos y resolver problemas específicos.

## 🚀 Proyectos Incluidos

Aquí encontrarás una variedad de aplicaciones y scripts:

### 1. 🧾 App de Facturación (`app_facturacion`)
Una aplicación de escritorio para la gestión y emisión de facturas. Cuenta con una interfaz de usuario orientada a simplificar la administración de ventas, control de productos y cálculo automático de totales.

### 2. 📊 Generador de Diagramas ER (`ER_generator`)
Herramienta diseñada para generar Diagramas de Entidad-Relación de manera programática. Ideal para documentar bases de datos y visualizar esquemas de forma rápida y estandarizada.

### 3. 📥 YouTube Downloader (`yt_downloader`)
Un práctico script para descargar videos de YouTube. Permite obtener contenido multimedia fácilmente indicando la URL, facilitando el acceso a material de estudio o entretenimiento offline.

### 4. 📄 Generador CV Harvard (`CV_harvard`)
Utilidad para formatear y generar Currículum Vitae siguiendo los estándares de diseño y estructura de Harvard. Pensado para lograr un perfil profesional limpio, directo y altamente efectivo en procesos de selección.

## 🛠️ Requisitos e Instalación

Para ejecutar la mayoría de estos proyectos necesitarás tener Python instalado en tu sistema.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Chacarerin/python_projects.git
   ```
2. Navega al directorio del proyecto que deseas usar:
   ```bash
   cd python_projects/<nombre_del_proyecto>
   ```
3. Revisa si existe un archivo `requirements.txt` dentro de la carpeta para instalar las dependencias necesarias:
   ```bash
   pip install -r requirements.txt
   ```
